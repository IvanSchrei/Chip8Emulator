This Project uses the SDL3 library. This is only needed for main.cpp, so if you feel like using another library you should only have to change that file.

After compiling you run your ROMs by passing the file as an argument in your CLI like this:
``./chip8.exe ./roms/flightrunner.ch8``

I tested it with both .ch8 and .rom files and both work but for other formats i give no guarantee.

Also feel free to play around with the Emulation speed at the end of main.cpp
